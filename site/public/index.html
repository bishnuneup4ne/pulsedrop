Hand it over, not upload it.

PulseDrop runs a server on your phone. Anything on the same Wi-Fi or hotspot — a laptop, another phone, a tablet — opens one address in its browser and can send files, chat, and start a call with screen sharing. Two PulseDrop phones pair end-to-end encrypted, so the traffic stays sealed even while it crosses the LAN. No internet, no accounts, no cloud.

    Three taps to the first transfer

    1. 1

      Start the server

      One phone is enough. It shows its address and a QR code; nothing needs to be installed on the other device.

    2. 2

      Open or pair

      A browser scans the code and enters the 4-digit PIN. Another PulseDrop phone appears on Radar and pairs with a safety code both screens can check.

    3. 3

      Move

      Drag files either way, chat with replies, or ring a call with camera or screen share. No Wi-Fi? Host a hotspot on the phone and join it.

    What is in the app

    Files, both ways

    Upload from a browser or the system share sheet, receive into WebDrop_Received/, and keep a filterable history of every send and receive. Multi-file selection included.

    Encrypted phone-to-phone

    Radar finds other PulseDrop devices on the subnet, pairs with an ECDH exchange, and seals everything between them with AES-GCM — including on a network you do not control.

    Calls and screen share

    Voice and video calls, front or back camera, and a screen you can share while you talk. A group call rings every member from one server.

    Stays running

    The server is a foreground service, so an open tab keeps working when the screen goes off or another app comes forward.

    Updates in-app

    PulseDrop checks GitHub on launch and whenever the network comes back, downloads the APK itself, and hands it to the installer — the count above is what that new install added.
